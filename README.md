# 🛴 Scootify – Electric Scooter Fleet Management System

**Scootify** is a web application designed to manage an electric scooter fleet, handle rentals, and coordinate maintenance operations. The system provides dedicated functionality for customers, administrators, and field operators, covering the entire vehicle lifecycle — from rental and monitoring to repair and relocation.

## 🎯 Project Goal

The goal of this project is to develop a comprehensive system for efficiently managing an electric scooter fleet, monitoring vehicle statuses, and streamlining customer support and field service operations.

## ✨ Features

### 👤 Guest (Unauthenticated User)
- Browse general information about the service and available scooters.
- View an overview map showing scooter locations.
- Access pricing information, terms of service, and FAQs.
- View company contact information.
- Register a new account and log in to the system.

### 🛴 Customer (Authenticated User)
- **Interactive Map** – view scooter locations and availability.
- **Scooter Rentals** – simulate unlocking a scooter and starting a ride.
- **Ride History** – browse previous rentals and completed rides.
- **Digital Wallet** – view the current account balance.
- **Profile Management** – edit personal information.
- **Fault Reporting** – report technical issues, such as a low battery or damaged brakes.

### 🛠️ Administrator
- **Fleet Management** – create, edit, and delete scooter records.
- **Rental Monitoring** – view rental records and current ride statuses.
- **Issue Management** – review and update maintenance reports.
- **Status Management** – monitor scooter availability and technical condition.
- **User Management** – manage accounts, block users, and assign permissions.
- **Maintenance Oversight** – monitor technical issues and maintenance requirements.
